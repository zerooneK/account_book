# Project Specific Rules

1. **Version Management**: Include a version number and update it whenever there is a change or feature update.
2. **Changelog**: Maintain a `CHANGELOG.md` file at the root of the project. Document all changes under each version.
3. **Git Commits**: Commit changes to Git every time the version is updated.
4. **Strict Plan Adherence**: Follow the implementation plan strictly. Do not deviate, add, or remove features from the plan without asking and getting explicit user approval first.
5. **README Update**: Always update the `README.md` file whenever updating or implementing new features to keep it up-to-date.
